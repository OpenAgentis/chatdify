# QuickNote 使用指南

## 简介

QuickNote 是一款轻量级的笔记应用，支持 Markdown 实时预览、跨设备同步以及端到端加密存储，适合开发者和学生日常使用。

## 安装

请从官方网站下载对应平台的安装包，并按照向导完成安装。安装完成后首次启动需要登录账号。

## 核心功能

1. Markdown 编辑与实时预览
2. 多设备自动同步
3. 全文搜索
4. 标签管理
5. 数据导出为 PDF 或 HTML

## 常见问题

如果同步失败，请检查网络连接，并确认账号已正确登录。如问题仍然存在，可在设置中开启同步日志并联系客服。

## 隐私声明

我们承诺不会读取或分析任何用户笔记内容，所有数据均在本地完成加密后再上传。
