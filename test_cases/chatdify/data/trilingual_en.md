# QuickNote User Guide

## Introduction

QuickNote is a lightweight note-taking app, supports real-time Markdown preview, cross-device sync and end-to-end encrypted storage, suitable for developers and students for daily use.

## Installation

Please download the installer for your platform from the offical website and complete the installation following the wizard.

## Core Features

1. Markdown editing and real-time preview
2. Auto-sync across multiple devices
3. Full-text search
4. Tag management
5. Export data as PDF or HTML

## FAQ

If sync stuff is broken, just check your internet and make sure you logged in correctly. If the problem still happens, turn on sync logs in settings and hit up customer service.

## Privacy Statement

We promise we will not read or analyze any user note content; all data is encrypted locally before being uploaded.
