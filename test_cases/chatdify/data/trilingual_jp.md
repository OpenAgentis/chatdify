# QuickNote 使い方ガイド

## はじめに

QuickNote は軽量なノートアプリで、リアルタイムの Markdown プレビュー、デバイス間同期、エンドツーエンド暗号化保存をサポートします。開発者や学生の日常利用に適しています。

## インストール

公式サイトからお使いのプラットフォーム向けインストーラをダウンロードし、ウィザードに従ってインストールしてください。インストール完了後、初回起動時にアカウントへのログインが必要です。

## 主な機能

1. Markdown 編集とリアルタイムプレビュー
2. 複数デバイスでの自動同期
3. 全文検索
4. タグ管理

## よくある質問

同期がうまくいかない時は、ネット接続を見て、アカウントがちゃんとログインしてるか確認してね。直んない時は設定で同期ログをオンにしてカスタマーサポートに連絡しといて。

## プライバシーに関する声明

私たちはユーザーのノート内容を読んだり分析したりすることはありません。すべてのデータはローカルで暗号化されてからアップロードされます。
